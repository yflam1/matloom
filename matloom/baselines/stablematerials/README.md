# StableMaterials

## Usage

```text
python matloom/baselines/stablematerials/run.py --prompt PROMPT [--out-dir OUT_DIR] [--use-consistency] [--resolution RESOLUTION] [--steps STEPS] [--scale SCALE] [--seed SEED]

options:
  --prompt PROMPT
  --out-dir OUT_DIR
  --use-consistency
  --resolution RESOLUTION
  --steps STEPS
  --scale SCALE
  --seed SEED
```
